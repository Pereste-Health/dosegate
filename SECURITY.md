# Security

DoseGate is a research release. It guarantees, by machine-checked proof, that released text states the values of the medication orders it receives; it does not check that those orders are correct, and its FHIR reader is tested, not proved. Do not use it as the only safeguard for patient-facing medication information.

To report a way to make the layer release text that misstates an order, email peresteai@gmail.com with the request and the reply. Please do not open a public issue for a release of a misstatement until it has been fixed.
